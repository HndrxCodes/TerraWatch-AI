Data Sources

TerraWatch AI uses publicly available Earth observation datasets to investigate environmental trends and variations across South Sumatra, Indonesia.

1. NASA GPM IMERG

- Variable: Precipitation
- Temporal coverage: 2000–2024
- Source: NASA Global Precipitation Measurement (GPM)

2. NASA MERRA-2

- Variable: Soil Moisture
- Source: NASA Modern-Era Retrospective Analysis for Research and Applications, Version 2

3. NASA FIRMS

- Variable: Active Fire Detections
- Source: Fire Information for Resource Management System (FIRMS)
- Satellite products: MODIS

Data Management

Raw datasets are not stored in this repository due to their size.

Users should obtain the original datasets from their respective official providers before reproducing the analysis.
